# Credit Card Spend & Default Risk Profiling

## Problem Statement
A consumer bank wants to understand the spending behavior and payment patterns of its credit card holders to reduce default rates. The analytics team must identify customer segments that are at higher risk of defaulting based on payment history and demographic details.

## Dataset
UCI Credit Card Default Dataset from Kaggle. It contains details of 30,000 credit card clients including demographics, credit limit, bill amounts, payment history, and default status.

## Tools Used
- Python
- Pandas
- NumPy 
- Power BI
- VS Code

## Work Done
- Data cleaning
- Feature understanding
- Default risk analysis
- Segment-wise analysis by gender, education, marriage, and age group
- Power BI dashboard creation

## Dashboard
The Power BI dashboard shows:
- Default rate by education
- Default rate by marriage
- Default rate by age group
- Payment amount analysis
- Credit limit and default comparison

## Conclusion
The project helps identify high-risk customer groups so that the bank can make better credit risk decisions.
